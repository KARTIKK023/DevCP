## 🌍 Overview

Engineering teams rely on multiple disconnected tools to manage their workflow:

* GitHub for code
* Meeting platforms for discussions
* Architecture tools for system design
* Documentation platforms for decisions
* Deployment dashboards for operations

DevSphere brings these workflows together into one unified platform, helping teams collaborate without losing context.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/devsphere.git
cd devsphere
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
